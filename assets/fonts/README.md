# Fuentes autoalojadas

Archivo (variable, peso 100–900) para cuerpo e interfaz; Archivo Black (peso 400 propio de la familia) para titulares. `font-display: swap` y fallback Arial/Helvetica/sans-serif. Georgia se conserva en la firma del pie.

Fuente oficial: https://github.com/google/fonts/tree/main/ofl/archivo y https://github.com/google/fonts/tree/main/ofl/archivoblack. Descargadas el 14 de octubre de 2026; licencias SIL Open Font License adjuntas. No se modifican los nombres de familia.

Conversión de TTF a WOFF2 con fontTools/Brotli y subconjunto U+0000–024F, U+2000–206F, U+2190–21FF y U+2700–27BF, preservando las funciones OpenType y ejes variables. Incluye español: ñ, tildes, ¿ y ¡. Tamaños: Archivo 130800 bytes, Archivo Black 26052 bytes.

El navegador solo solicita archivos locales; no se cargan Google Fonts ni otros proveedores de fuentes en tiempo de visita.
